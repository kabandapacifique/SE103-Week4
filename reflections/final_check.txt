What a pull request asks teammates to do:
A pull request asks teammates to review proposed changes before they are merged into the main branch. Reviewers can check the files, comments, and changes and provide feedback.

Why branches and pull requests are used together:
Branches allow developers to work on changes separately from the main branch. Pull requests then provide a way to review those changes before they are merged into the main branch. Together, they support organized and collaborative development.

I learned that a branch is where I make and save my changes, while a pull request is used to ask for those changes to be reviewed and merged.

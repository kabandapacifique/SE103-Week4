Problem:
Search a list of names for one target name and report whether it was found.

Input:
- a list of names
- one target name

Output:
- "Found" or "Not found"
- or an error if the list is empty

Pseudocode:
START
1. IF the list of names is empty THEN
      Return "Error: list is empty"
   ELSE
      Set found to FALSE.
2. FOR each name in the list DO
      IF the name matches the target name THEN
         Set found to TRUE.
         Stop searching.
      END IF
   END FOR
3. IF found is TRUE THEN
      Return "Found"
   ELSE
      Return "Not found"
   END IF
END
